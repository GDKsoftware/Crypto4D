# Security policy

## Reporting a vulnerability

Report a vulnerability through GitHub private vulnerability reporting: open the Security tab of this
repository and choose "Report a vulnerability". Do not open a public issue for it.

Say which function is affected and include the input that shows the problem: the public key, the message
and the signature, or the certificate.

## Supported versions

Only the latest commit on `main` is supported. A fix lands there; older commits are not patched.

## Audit status

This library has not been audited by an external party. The README describes what the tests cover.
